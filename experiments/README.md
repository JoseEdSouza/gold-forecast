# Experimentos

O repositório está organizado em duas trilhas:

- `baseline`: baseline clássico com regressão linear sobre lags de log-retorno.
- `price_cnn`: previsão do preço futuro do ouro via log-retornos e CNN 1D causal.
- `volatility`: previsão de volatilidade futura do ouro com GRU e variáveis macro/mercado.
